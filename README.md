# SKYPARK EXTREME | Edge of Adrenaline 🎡⚡

**Engineered by:** [Kipler](https://github.com/Aziz-Kipler)  
**Live Demo:** [https://aziz-kipler.github.io/skypark-extreme/](https://aziz-kipler.github.io/skypark-extreme/)

Ультрадинамичный интерактивный веб-проект экстремального высокогорного парка аттракционов с передовой кинематикой, физикой ускорений и геймификацией.

## Ключевые возможности:
- 🎡 **Векторное Колесо Обозрения:** фиксированный верхний слой (`z-index: 999`), вращение против часовой стрелки с плавным подъемом и физической инерцией скролла.
- 🚨 **PANIC MODE:** мгновенная тревожная пульсация алого освещения, реалистичный EKG кардиограф с пульсом адреналина в реальном времени.
- 🦊 **Интерактивный Маскот:** гироскоп и 3D mouse-параллакс над пропастью каньона.
- 🚀 **Катапульта Slingshot Launch:** динамическое натяжение неонового троса и звуковые микроэффекты.
- ⭐ **Модуль отзывов:** защита Google OAuth, автоматический расчет рейтинга с полузвездами и санитизация XSS.
